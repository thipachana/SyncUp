# SyncUp Frontend

Das Frontend von SyncUp wurde mit React und Vite entwickelt.

Es stellt die Benutzeroberfläche für die aktuellen Funktionen der Anwendung bereit.

Aktuell können unter anderem:

- Terminanfragen erstellt, angezeigt und gelöscht werden
- freie Zeitfenster angezeigt werden
- Ressourcen angezeigt werden
- Ressourcen für vorhandene Termine gebucht werden

Das Frontend kommuniziert über REST mit dem Spring-Boot-Backend.

Die Adresse des Backends wird über `VITE_API_URL` eingestellt.

Weitere Informationen zur Installation befinden sich in der Datei `INSTALL.md` im Hauptverzeichnis des Projekts.
