# Übergabe und Integration

Stand: 24.09.2026

## Zweck

Dieses Dokument beschreibt kurz, wie die letzten Änderungen im Team zusammengeführt und geprüft wurden.

## Zuständigkeiten

- David prüft Änderungen am Backend, an der Datenbank und an den Backend-Tests.
- Sarah prüft Änderungen am Frontend und an den zugehörigen Architekturtexten.
- Thipachana prüft die Spezifikation, README, Installation sowie Test- und Demo-Dokumentation.
- Ilias prüft die technische Integration und den Gesamtstand des Projekts.

## Vorgehen

Änderungen werden vor dem Commit von der zuständigen Person geprüft.

Dabei werden insbesondere folgende Punkte kontrolliert:

- Build und Tests laufen erfolgreich.
- Der Code entspricht dem aktuellen Stand der Spezifikation.
- Es entstehen keine unbeabsichtigten Änderungen.
- Commit-Nachrichten folgen dem Conventional-Commits-Schema.
- Änderungen werden auf den gemeinsamen `main`-Branch übernommen.

Force-Pushes werden vermieden.

## Abschluss

Vor der finalen Abgabe wird geprüft, ob:

- alle relevanten Änderungen auf `main` vorhanden sind,
- Frontend und Backend erfolgreich gebaut werden können,
- die wichtigsten Funktionen getestet wurden,
- Spezifikation, Architektur und Implementierung zusammenpassen,
- die finale Version mit dem vorgesehenen Git-Tag markiert wurde.
