# Eingesetzte KI-Werkzeuge

Im Projekt wurden KI-Werkzeuge unterstützend eingesetzt.

## ChatGPT

ChatGPT wurde vor allem verwendet für:

- Formulierung und Überarbeitung der Dokumentation
- Strukturierung einzelner Dokumente
- Unterstützung bei Git und GitHub
- Unterstützung bei technischen Fragen
- Fehlersuche und Erklärung von Code
- Vorbereitung und Überarbeitung von Testfällen

## Codex

Codex wurde ergänzend für die Prüfung und Überarbeitung einzelner Codestellen eingesetzt.

Dabei ging es unter anderem um:

- Sitzungsverwaltung
- Eingabeprüfungen
- Zugriff auf persönliche Daten
- Ressourcenbuchungen
- React-Zustände
- Unterstützung bei Tests

## Umgang mit KI-Vorschlägen

Die Vorschläge der KI wurden nicht ungeprüft übernommen.

Sie wurden an den tatsächlichen Stand von SyncUp angepasst und vom Team überprüft.

Änderungen wurden je nach Bereich zusätzlich durch:

- Builds
- automatisierte Tests
- manuelle Funktionsprüfungen
- gemeinsame Tests im Team

überprüft.

Die Entscheidung darüber, welche Änderungen tatsächlich übernommen wurden, lag beim Projektteam.

Alle Teammitglieder sollen die verwendeten Inhalte und übernommenen Änderungen verstehen und erklären können.

Weitere Informationen zu den durchgeführten Tests befinden sich in `docs/TESTING.md`.
