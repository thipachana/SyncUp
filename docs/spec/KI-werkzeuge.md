# Eingesetzte KI-Werkzeuge

Im Rahmen des Projekts wurde ChatGPT zur Unterstützung bei der Strukturierung und Formulierung von Dokumentationsentwürfen sowie bei Fragen zu Git und GitHub verwendet.

Die erzeugten Vorschläge wurden vom Team geprüft, an das Projekt SyncUp angepasst und bei Bedarf überarbeitet. Die fachlichen und technischen Entscheidungen wurden anschließend gemeinsam im Team abgestimmt.
