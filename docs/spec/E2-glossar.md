# E2 Glossar

Stand: 24.09.2026

| Begriff | Erklärung |
| --- | --- |
| React | JavaScript-Bibliothek für die Benutzeroberfläche. |
| Vite | Werkzeug zum Starten, Entwickeln und Erstellen des Frontends. |
| Spring Boot | Java-Framework für das Backend. |
| PostgreSQL | Relationale Datenbank zur dauerhaften Speicherung der Anwendungsdaten. |
| REST | Architekturprinzip für die Kommunikation zwischen Frontend und Backend über HTTP-Schnittstellen. |
| API | Schnittstelle zum Austausch von Daten zwischen verschiedenen Teilen der Anwendung. |
| Frontend | Der Teil der Anwendung, den der Benutzer sieht und bedient. |
| Backend | Der serverseitige Teil der Anwendung, der Daten verarbeitet und Geschäftslogik ausführt. |
| Repository | Git-Projekt, in dem Quellcode und Dokumentation verwaltet werden. |
| JPA | Java-Schnittstelle zur Abbildung von Java-Objekten auf Datenbankstrukturen. |
| Hibernate | JPA-Implementierung, die den Datenbankzugriff im Backend unterstützt. |
| Benutzer | Person, die SyncUp verwendet und sich registrieren sowie anmelden kann. |
| Kalender | Sammlung von Terminen eines Benutzers. |
| Termin | Festgelegter Zeitraum mit Datum, Startzeit, Endzeit und weiteren Angaben. |
| Privater Termin | Termin, der nur zum persönlichen Kalender eines Benutzers gehört und keine Teilnehmerauswahl besitzt. |
| Gemeinsamer Termin | Termin, der mehreren beteiligten Benutzern zugeordnet ist. |
| Terminanfrage | Anfrage zur Suche nach einem gemeinsamen freien Zeitpunkt für mehrere Benutzer. |
| Teilnehmer | Benutzer, die einer Terminanfrage oder einem gemeinsamen Termin zugeordnet sind. |
| Suchzeitraum | Zeitraum, innerhalb dessen nach gemeinsamen freien Zeitfenstern gesucht wird. |
| Termindauer | Gewünschte Länge eines gemeinsamen Termins. |
| Zeitslot | Ein möglicher gemeinsamer freier Zeitraum für einen Termin. |
| Ressource | Buchbares Objekt innerhalb von SyncUp, zum Beispiel ein Raum. |
| Raum | Ressource, die einem bestehenden Termin zugeordnet werden kann. |
| Buchung | Verbindet einen Termin mit einer Ressource. Der Buchungszeitraum ergibt sich aus dem zugehörigen Termin. |
| Raumverfügbarkeit | Information darüber, ob ein Raum im Zeitraum eines ausgewählten Termins verfügbar oder bereits belegt ist. |
| Überschneidung | Zeitlicher Konflikt zwischen zwei Buchungen derselben Ressource. |
| Benachrichtigung | Meldung innerhalb von SyncUp über ein relevantes Ereignis, zum Beispiel einen neu erstellten gemeinsamen Termin. |
| Session | Serverseitige Sitzung zur Wiedererkennung eines angemeldeten Benutzers. |
| CSRF | Schutzmechanismus gegen unerwünschte schreibende Anfragen über eine bestehende Sitzung. |
| BCrypt | Verfahren zum sicheren Hashen von Passwörtern. |
| Tailscale | Werkzeug zur internen gemeinsamen Testumgebung des Teams. |
