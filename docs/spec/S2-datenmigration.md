# S2 Datenmigration

Stand: 24.09.2026

## Beschreibung

Für SyncUp ist keine Datenmigration aus einem bestehenden Fremdsystem notwendig.

Alle benötigten Daten werden direkt in der PostgreSQL-Datenbank von SyncUp angelegt und gespeichert.

## Begründung

SyncUp ersetzt keine bereits vorhandene Anwendung.

Deshalb müssen keine bestehenden Daten aus einem anderen System übernommen oder konvertiert werden.
