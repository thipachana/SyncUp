# F1 Geschäftsprozesse

## Ziel

Dieser Abschnitt beschreibt die wichtigsten Geschäftsprozesse der Webanwendung SyncUp. Ziel ist es, die Planung und Organisation gemeinsamer Termine sowie die Verwaltung von Ressourcen zu vereinfachen.

## Geschäftsprozess 1: Gemeinsamen Termin planen

1.⁠ ⁠Ein Benutzer meldet sich bei SyncUp an.
2.⁠ ⁠Der Benutzer erstellt eine neue Terminanfrage.
3.⁠ ⁠Titel, Datum, Uhrzeit und Teilnehmer werden eingetragen.
4.⁠ ⁠SyncUp prüft die Kalender aller Teilnehmer.
5.⁠ ⁠Freie gemeinsame Zeitfenster werden vorgeschlagen.
6.⁠ ⁠Der Organisator wählt einen passenden Termin aus.
7.⁠ ⁠Alle Teilnehmer erhalten den Termin in ihrem Kalender.

## Geschäftsprozess 2: Ressource reservieren

1.⁠ ⁠Der Benutzer erstellt einen Termin.
2.⁠ ⁠Eine Ressource (z. B. Besprechungsraum) wird ausgewählt.
3.⁠ ⁠SyncUp prüft die Verfügbarkeit.
4.⁠ ⁠Ist die Ressource frei, wird sie reserviert.
5.⁠ ⁠Ist sie bereits belegt, werden Alternativen vorgeschlagen.

## Geschäftsprozess 3: Termin verwalten

1.⁠ ⁠Ein Benutzer öffnet einen bestehenden Termin.
2.⁠ ⁠Änderungen können vorgenommen werden.
3.⁠ ⁠Teilnehmer werden automatisch informiert.
4.⁠ ⁠Der Kalender wird aktualisiert.

## Beteiligte Rollen

•⁠  ⁠Organisator
•⁠  ⁠Teilnehmer
•⁠  ⁠Administrator

## Nicht anwendbare Punkte

Geschäftsprozesse wie Rechnungsstellung, Zahlungsabwicklung oder Warenverwaltung sind für SyncUp nicht relevant.
