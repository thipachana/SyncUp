# D2. Datentypenverzeichnis

| Datentyp | Beschreibung |
|----------|--------------|
| Benutzer | Enthält Informationen zu einem Benutzer der Anwendung. |
| Kalender | Enthält alle Termine eines Benutzers. |
| Termin | Beschreibt einen geplanten Termin mit Datum und Uhrzeit. |
| Ressource | Beschreibt buchbare Ressourcen, z. B. Räume. |
| Aufgabe | Beschreibt eine Aufgabe innerhalb der Anwendung. |
| Zeitslot | Repräsentiert einen freien Zeitraum für einen möglichen Termin. |
