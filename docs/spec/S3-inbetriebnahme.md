# S3. Inbetriebnahme

## Ziel

Die Inbetriebnahme beschreibt die grundlegenden Schritte, um SyncUp lokal auszuführen.

## Voraussetzungen

- Node.js
- Java 21
- Maven
- PostgreSQL
- Git

## Installation

1. Repository klonen.
2. PostgreSQL-Datenbank erstellen.
3. Backend mit Maven starten.
4. Frontend mit npm installieren und starten.
5. Anwendung im Browser öffnen.

## Hinweis

Eine ausführliche Installationsanleitung befindet sich in der Datei `INSTALL.md` im Hauptverzeichnis des Repositorys.
