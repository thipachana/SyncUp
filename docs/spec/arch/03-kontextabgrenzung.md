# 3. Kontextabgrenzung

## Systemkontext

SyncUp ist eine Webanwendung zur Planung gemeinsamer Termine. Das System kommuniziert mit seinen Benutzern über einen Webbrowser.

In der ersten Version werden keine externen Systeme angebunden. Die Verwaltung von Benutzern, Kalendern, Terminen und Ressourcen erfolgt vollständig innerhalb von SyncUp.

## Externe Akteure

- Benutzer
- Administrator

## Nachbarsysteme

Derzeit sind keine externen Nachbarsysteme vorgesehen. Eine spätere Anbindung an Kalenderdienste wie Google Calendar oder Microsoft Outlook ist möglich, gehört jedoch nicht zum Umfang der ersten Version.

## Abgrenzung des Systems

Innerhalb von SyncUp befinden sich die Benutzerverwaltung, Kalenderverwaltung, Terminplanung, die Berechnung gemeinsamer freier Zeitfenster sowie die Ressourcenverwaltung.

Nicht Bestandteil der ersten Version sind externe Kalenderdienste oder andere Fremdsysteme. Diese können in zukünftigen Versionen über zusätzliche Schnittstellen angebunden werden.
