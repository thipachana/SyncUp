# 2. Randbedingungen

## Technische Randbedingungen

Für die Entwicklung von SyncUp werden folgende Technologien verwendet:

- Frontend: React
- Backend: Spring Boot
- Datenbank: PostgreSQL

Die Kommunikation zwischen Frontend und Backend erfolgt über REST-Schnittstellen.

## Organisatorische Randbedingungen

Das Projekt wird im Rahmen des Moduls Wirtschaftsinformatik-Projekt I an der THM entwickelt.

Die Entwicklung erfolgt im Team und wird mit Git und GitHub versioniert.

## Qualitätsziele

Bei der Architektur stehen folgende Ziele im Vordergrund:

- Wartbarkeit
- Erweiterbarkeit
- Übersichtlichkeit
- Klare Trennung der Komponenten
