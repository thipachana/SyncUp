# Eingesetzte KI-Werkzeuge

Stand: 24.09.2026

Im Projekt wurden KI-Werkzeuge unterstützend eingesetzt.

## ChatGPT

ChatGPT wurde unter anderem verwendet für:

- Strukturierung und Überarbeitung der Projektdokumentation
- Unterstützung bei der arc42-Architekturdokumentation
- Formulierung und Überarbeitung von Architekturentscheidungen
- technische Fragen zu Frontend, Backend und Datenbank
- Fehlersuche und Erklärung von Code
- Unterstützung bei Git und GitHub
- Vorbereitung von Testfällen und Prüfabläufen

Die vorgeschlagenen Inhalte wurden an den tatsächlichen Stand von SyncUp angepasst.

Architekturentscheidungen wie die Verwendung von React, Spring Boot, PostgreSQL und REST wurden im Team getroffen und in der Architekturdokumentation beziehungsweise den ADRs festgehalten.

## Codex

Codex wurde zusätzlich bei einzelnen technischen Prüfungen und Änderungen eingesetzt.

Dazu gehörten unter anderem:

- Prüfung der Sitzungsverwaltung
- Eingabevalidierung
- Zugriff auf persönliche Daten
- Prüfung von Ressourcenbuchungen
- Behandlung paralleler Buchungsversuche
- Prüfung von React-Zuständen
- Unterstützung bei automatisierten Tests

Die vorhandene Benutzeroberfläche und der grundsätzliche Aufbau des Projekts wurden dabei beibehalten.

## Prüfung der Ergebnisse

KI-generierte Vorschläge wurden nicht ungeprüft übernommen.

Die Änderungen wurden vom Team nachvollzogen, angepasst und je nach Bereich durch:

- automatisierte Tests,
- Builds,
- manuelle Prüfungen im Browser
- und gemeinsame Funktionstests

überprüft.

Der aktuelle Teststand ist in `docs/TESTING.md` dokumentiert.

Die endgültige Entscheidung, welche Vorschläge übernommen werden, lag beim Team.

Alle Teammitglieder sollen die übernommenen Änderungen nachvollziehen und im Rahmen der Präsentation erklären können.
