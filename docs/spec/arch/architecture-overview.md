# Architekturübersicht

## Ziel

SyncUp ist eine Webanwendung zur gemeinsamen Planung von Terminen, Aufgaben und Ressourcen.

## Systemstruktur

Das System besteht aus:

- Frontend
- Backend
- Datenbank

## Technologien

- Frontend: React
- Backend: Spring Boot
- Datenbank: PostgreSQL

## Komponenten

- Benutzerverwaltung
- Kalenderverwaltung
- Terminplanung
- Ressourcenverwaltung
