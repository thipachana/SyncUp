# 12. Glossar

| Begriff | Erklärung |
|----------|-----------|
| React | JavaScript-Bibliothek zur Entwicklung der Benutzeroberfläche |
| Spring Boot | Java-Framework zur Entwicklung des Backends und von REST-Schnittstellen |
| PostgreSQL | Relationale Datenbank zur dauerhaften Speicherung der Anwendungsdaten |
| REST | Architekturprinzip für die Kommunikation zwischen Frontend und Backend über HTTP |
| API | Programmierschnittstelle für den Datenaustausch zwischen Softwarekomponenten |
| Frontend | Benutzeroberfläche, mit der die Anwender arbeiten |
| Backend | Serverseitiger Teil der Anwendung mit der Geschäftslogik |
| Repository | Git-Projekt, das den Quellcode und die Dokumentation enthält |
| Controller | Bestandteil des Backends, der REST-Anfragen entgegennimmt und verarbeitet |
| Service | Bestandteil des Backends, in dem zentrale Geschäftslogik verarbeitet wird |
| Repository-Schicht | Bestandteil des Backends für den Zugriff auf gespeicherte Daten |
| Entity | Java-Klasse, die ein dauerhaft gespeichertes Datenobjekt abbildet |
| Kalender | Sammlung von Terminen eines Benutzers |
| Termin | Ein geplanter Zeitraum mit Titel, Datum sowie Start- und Endzeit |
| Privater Termin | Termin, der nur im persönlichen Kalender eines Benutzers vorhanden ist und keine Teilnehmerauswahl besitzt |
| Gemeinsamer Termin | Termin, der mehreren beteiligten Benutzern zugeordnet ist |
| Terminanfrage | Anfrage zur Suche nach einem gemeinsamen freien Zeitpunkt für mehrere Benutzer |
| Teilnehmer | Benutzer, die einer Terminanfrage oder einem gemeinsamen Termin zugeordnet sind |
| Zeitslot | Gemeinsames freies Zeitfenster, das für einen Termin ausgewählt werden kann |
| Suchzeitraum | Zeitraum, innerhalb dessen gemeinsame freie Zeitfenster gesucht werden |
| Termindauer | Gewünschte Dauer eines gemeinsamen Termins |
| Ressource | Buchbares Objekt innerhalb von SyncUp, zum Beispiel ein Raum |
| Raum | Ressource, die einem bestehenden Termin zugeordnet werden kann |
| Buchung | Zuordnung einer Ressource zu einem bestehenden Termin |
| Raumverfügbarkeit | Information darüber, ob ein Raum im Zeitraum eines ausgewählten Termins frei oder bereits belegt ist |
| Überschneidung | Zeitlicher Konflikt zwischen zwei Buchungen desselben Raumes |
| Benachrichtigung | Meldung innerhalb von SyncUp über ein relevantes Ereignis, zum Beispiel einen neu festgelegten gemeinsamen Termin |
| Session | Serverseitige Sitzung, mit der ein angemeldeter Benutzer während der Nutzung erkannt wird |
| CSRF | Schutzmechanismus gegen unerwünschte schreibende Anfragen über eine bestehende Sitzung |
| BCrypt | Verfahren zum sicheren Hashen von Passwörtern |
| JPA | Java-Schnittstelle zur Abbildung von Java-Objekten auf Datenbanktabellen |
| Hibernate | JPA-Implementierung, die den Datenbankzugriff im Backend unterstützt |
| Vite | Werkzeug zum Entwickeln und Bauen des React-Frontends |
| Maven Wrapper | Im Projekt enthaltenes Werkzeug zum Ausführen von Maven-Befehlen ohne separate Maven-Installation |
| Tailscale | Werkzeug, mit dem die gemeinsame Testumgebung innerhalb des Teams erreichbar gemacht wird |
| Tailnet | Privates Netzwerk innerhalb von Tailscale, über das die Teammitglieder auf die gemeinsame Testumgebung zugreifen |
