# SyncUp – Test- und Demo-Checkliste

## 1. Backend
- [ ] Spring Boot startet ohne Fehler
- [ ] PostgreSQL-Verbindung funktioniert
- [ ] API liefert Termine
- [ ] API liefert Terminanfragen
- [ ] API liefert Ressourcen
- [ ] API liefert Buchungen

## 2. Terminplanung
- [ ] Terminanfrage wird angezeigt

## 3. Ressourcen
- [ ] Raum A101 wird angezeigt

- [ ] Buchung wird gespeichert

- [ ] Passwort wird nicht in API-Antworten angezeigt

## 5. Frontend
- [ ] Frontend startet ohne Fehler

- [ ] Ressourcen werden angezeigt
